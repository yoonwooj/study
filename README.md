# 초등 국어·도덕 문제 풀이 (React + Vite)

    npm install
    npm run dev      # 개발 서버
    npm run build    # 배포용 빌드 (dist/)

- `src/curriculum.js` : 목차 기준 과목·학년·학기별 단원 목록
- `src/bank.js` : 문제 은행 (키 `과목-학년-학기-단원번호`, 단원당 6문제). 문제가 없는 단원은 "준비 중"으로 표시됩니다.
  - 객관식은 정답을 첫 번째로 쓰면 앱이 보기를 섞어 정답 번호가 골고루 나옵니다. O/X는 정답이 반반이 되게 작성하세요.
- `src/legacy/` : 이전 버전 문제(사용 안 함, 보관용)
